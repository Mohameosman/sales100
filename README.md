# Sales100 – المرحلة الأولى

تطبيق ويب ثابت يعمل مباشرة على GitHub Pages.

## الملفات
- index.html
- styles.css
- app.js
- mock-data.js

## النشر
ارفع الملفات الأربعة إلى جذر المستودع ثم فعّل GitHub Pages من:
Settings → Pages → Deploy from branch → main → /(root)

## الوظائف
- مصفوفة شهرية: 10 مندوبي مبيعات × 100 عميل × 30 يومًا
- فتح وإغلاق عملاء كل مندوب
- فلترة حسب المنطقة والمندوب والعميل
- بحث سريع
- تبديل بين قيمة المبيعات وعدد الحجوزات
- تصدير CSV
- طباعة
- بطاقات مؤشرات الأداء
- أفضل العملاء والمندوبين
- نافذة تفاصيل عند الضغط على خلية يومية
